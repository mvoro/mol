Дата: 8 сентября 2026. Приложение: http://127.0.0.1:5190/; каталог: /components.

## Последние пользовательские изменения

Последние указания пользователя имеют приоритет над исходной Figma: 16 px по бокам на мобильном, проекты вместо модели в шапке, вложенность только через «+», светлый текстовый шиммер и единые компоненты контролов.

- **Консистентность:** `TextInput` / `InputShell` используются в создании проекта, поиске истории, моделей и ролей. Manrope 14/500, белая поверхность, обводка #e7e7e7 и radius 64 px заданы в общем CSS. Высота 40 px, у имени проекта 44 px. Верхний ProjectSelect использует общий `pill`: #f7f7f7, radius 64 px, Manrope.
- **Проекты:** создание с проверкой пустого и повторяющегося имени, выбор, перенос текущего чата, вложенные чаты и восстановление после перезагрузки проверены через UI. Перенос не создаёт дубликат; чаты с одинаковыми названиями различаются по id. Исправлены возврат в текущий чат во время стрима и сохранение демонстрационного чата при переносе. Перед pagehide сохраняется незавершённый ответ; пустой прерванный ответ не показывает вечное ожидание.
- **Меню:** прямой клик «Качество: 1K» — 1 панель, 0 подменю. «+» → «Качество» — 2 панели, 1 подменю. Выбор значения и Escape работают. Автотесты охватывают прямые панели всех режимов и размещение у границ.
- **Мобильная ширина:** при 360 px x=16, width=328; при 414 px x=16, width=382. Проверены пустой композер и нижний композер переписки. Горизонтального переполнения нет.
- **Сайдбар:** раскрытие через grid 0fr→1fr, поворот стрелки, вертикальная направляющая, сворачивание ширины 248→0. Mobile: фокус входит в меню, Shift+Tab замыкает цикл, Escape закрывает. На невысоких экранах верхнее содержимое прокручивается вместе.
- **Шиммер:** текст и data-text совпадают; ::before имеет background-clip:text, 400% 100% и 4s linear infinite. Стили отключают эффект при reduced motion/forced colors.
- **Адаптивный footer:** при ширине композера до 640 px табы заменяются общим компактным выбором типа; в viewport 768 px обе кнопки находятся внутри footer.
- **Проверки:** финальные `npm test` — 13/13, `npm run build` — успешно. Чистая вкладка: console errors/warnings = 0, битых изображений = 0.

## Findings

Активных P0/P1/P2 в проверенных экранах и сценариях не осталось.

- **P3 · Снимки градиента.** Промежуточные захваты браузера показывали более светлый правый край. В финальном чистом захвате насыщенность восстановилась; исходный SVG radialGradient из design context, stops и transform сохранены. Различия сглаживания на границах допустимы.
- **P3 · Растровое сглаживание.** В снимках браузера мелкие надписи/иконки слегка мягче экспорта Figma. Шрифты, размеры и начертания сверены по design context; используются локальные Manrope Variable и Geist Variable.

## Primary interactions tested

- Пять режимов и собственные настройки: скорость Авто, качество картинки4K, text search/research, параметры видео и аудио.
- Выбор модели, поиск, пустой результат поиска, выбор ChatGPT5.5, запрет смены при генерации.
- Поиск роли, описание менеджера маркетплейсов, применение роли и подсказки в композер; корректно один modal overlay.
- Ввод, многострочное поле, отправка, потоковый демонстрационный ответ, остановка и повторная доступность выбора модели.
- ФайлTXT через нативный выбор: отображение и удаление.
- Kling без начального кадра: запрос не отправляется, показывается ошибка. Загрузка PNG устраняет ошибку и показывает превью.
- Mobile type bottom sheet: выбор Audio→Text, закрытие, снятие scroll lock, корректное восстановление фокуса.
- Каталог:21 живой композер, все состояния, переключение общей матрицы наAudio, file/ref карточки, menu rows, badges, model rows, tooltip.
- Desktop1920×1080 и mobile360×648: нет горизонтального переполнения. Смена ширины пересчитывает поле.
- Settings placement дополнительно проверен на2160 комбинациях координат/размеров; меню остаются в доступной области.
- Чистый запуск в новой вкладке: console errors/warnings отсутствуют. Историческое HMR-предупреждение о смене deps после редактирования кода не воспроизводится после загрузки.
- `npm run build` — успешно. `npm test` —13/13 успешно (включая4 Sites checks), проверен fallback маршрута и статические ресурсы.

## Open questions / test gaps

AI API, авторизация, платежи и серверное хранение не подключались: проверяется React frontend и состояние флоу. Дополнительные медиа-модели нужны для демонстрации переключения; их наличие/цены не проверялись как актуальный коммерческий каталог. Голосовой ввод реализован через Web Speech API, но микрофон и разрешения ОС не проверялись. Проверка выполнялась в Chromium внутри Codex; отдельный Safari/iOS и физическая экранная клавиатура не тестировались. Системная отрисовка каретки следует возможностям браузера.
