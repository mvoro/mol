# Молекула — новый композер и флоу чата

React-приложение по секции Figma `2335:87500` (UX rework, iteration 09).

## Публичная версия

[Открыть проект](https://mvoro.github.io/mol/) · [Демо документов PDF / DOCX / MD](https://mvoro.github.io/mol/?chat=molecula-document-demo-v1).

GitHub Actions автоматически тестирует, собирает и публикует `main` на GitHub Pages. `npm run build:pages` создаёт статический сайт в `dist/client` с префиксом `/mol/` и отдельными входными HTML для прямых ссылок на карусели, тренды, роли и компоненты.

Для Vercel в `vercel.json` явно заданы `npm run build`, выходная папка `dist/client` и переходы SPA. Обычная сборка сохраняет совместимость с Sites и размещением в корне домена.

## Запуск

```sh
pnpm install
pnpm dev -- --host 127.0.0.1 --port 5190
```

- `/` — работающий флоу чата.
- `/components` — каталог компонентов, вариантов и состояний по прямой ссылке.
- `/carousel` — выбор стиля и настройка карусели, история, просмотр и экспорт готовых слайдов.
- `/trends` — шаблоны камеры, загрузка персонажа и создание видео.
- `npm run build` — production build в `dist/client`.
- `npm test` — проверки сохранения чатов, проектов, настроек и упаковки приложения.

## Реализовано

Авто / текст / картинка / видео / аудио, собственные настройки и модель на каждый режим. Пустой чат и переписка, ввод многострочного сообщения, отправка и остановка потокового демонстрационного ответа, история чатов, поиск, выбор модели, поиск и выбор роли, описание роли, файлы и обязательные референсы для Kling. Быстрые действия открывают отдельные поповеры значений; вложенность есть только в меню «+». На мобильном — нижние листы. Enter отправляет, Shift+Enter переносит строку; Cmd/Ctrl+1…5 переключает режимы, Cmd/Ctrl+K открывает поиск чатов.

Проекты доступны в верхней серой пилюле и сайдбаре. Иконка проекта — контурная Lucide Folders без заливки, с сохранением выбранного цвета. Создание проекта, вложенные чаты, перенос текущей переписки через верхний переключатель и восстановление после перезагрузки работают через localStorage. Раскрытие проектов и сворачивание сайдбара анимированы. На мобильном у композера ровно 16 px по бокам. Шиммер «Молли ждёт ваш запрос…» проходит по буквам раз в 4 секунды.

Общие TextInput/InputShell используются для имени проекта и поиска чатов, моделей и ролей. Фон, обводка, скругление, Manrope и состояния фокуса заданы в одном месте; высота поля — параметр компонента. Кнопки проекта повторно используют общий стиль pill.

50 сочетаний композера: 5 типов × 5 состояний × 2 устройства. Опциональные панели Assistant / Role / Offer, footer, promo, file chips, UploadRefCard. Галерея повторно использует компоненты основного приложения.

Контурные UI-иконки переведены на Lucide React с единой толщиной 1.75. Фирменные логотипы и изображения Figma сохранены локально в `public/figma`, `public/assets/models`, `public/assets/composer`. Шрифты Manrope и Geist загружаются локально. Анимации поддерживают reduced motion; действия с клавиатуры выполняются без анимаций.

## Границы прототипа

AI API, авторизация и платежи не подключены. Ответы и медиа в чате демонстрационные: изображения, видео и аудио используют готовые примеры. Студии каруселей и трендов создают локальные композиции из выбранных ассетов и загруженных фото, как описано ниже. Голосовой ввод использует Web Speech API, когда браузер его поддерживает, и сообщает об отсутствии поддержки. История текстов сохраняется только в localStorage этого браузера; бинарные вложения не сохраняются между перезагрузками. Модели и цены — подписи из макетов, не коммерческое предложение.

## Дополнения текущей итерации

Сайдбар на десктопе сворачивается в колонку иконок. Переключение использует Lucide PanelLeft/PanelRight: размер уменьшен на 15%, толщина 1.75 совпадает с SquarePlus у нового чата. Разворачивание доступно при наведении/фокусе на логотип и по невидимой зоне вдоль края. Ширина сохраняется; верхние actions и кнопка сворачивания выровнены. «Карусель» и «Тренды» заменяют «Файлы и медиа», каталог «Инструменты» скрыт из сайдбара и доступен по прямому `/components`.

В карусели 20 готовых стилей с фонами, созданными встроенным imagegen. Настройки слева, каталог стилей справа — тот же layout, что в «Трендах». «Свой стиль» — отдельная первая карточка каталога с обязательным описанием и необязательными 0–5 фото (JPG/PNG/WebP до 15 МБ). Описание локально выбирает палитру и шрифт, а загруженные фотографии включаются в композицию слайдов; это не генеративная интерпретация референсов. Доступны 3–10 слайдов, 1:1 / 4:5 / 9:16 и настоящие PNG/ZIP экспорты. Текст задаётся перед генерацией: готовый текст раскладывается по слайдам, короткая тема превращается в план. Сгенерированная карусель доступна только для просмотра и скачивания, без редактирования. Это локальная композиция без AI-копирайтинга. Черновик и последние 12 каруселей сохраняются в браузере; фотографии — в IndexedDB, их метаданные вместе с параметрами результата. Заголовки обеих студий совпадают с приветствием: Geist 28px на десктопе, 24px на мобильном.

В «Трендах» восемь шаблонов движения камеры применяются к загруженному JPG/PNG/WebP. Шестисекундное видео 9:16 записывается в браузере через Canvas/MediaRecorder в 720p или 1080p, с подписью и скачиванием. Фото, черновик и последние шесть видео сохраняются в IndexedDB. Завершение обоих сценариев создаёт уведомление, открывающее конкретный сохранённый результат. Для переноса поз/мимики из референсного видео, генерации новых изображений по теме и AI-написания текста нужен отдельный сервер генерации; эти возможности не имитируются чужим готовым видео.

В каруселях вкладки «Шаблоны» и «Мои карусели» используют общий Tabs, как в трендах. История показывает реальные обложки последних 12 работ. Обе истории открывают результаты в общем MediaViewer: карусели — с переключением слайдов и PNG/ZIP экспортом, тренды — с видеоплеером и скачиванием. Закрытие возвращает в историю, сохраняя черновик настроек.

В обеих студиях настройки на десктопе закреплены под шапкой при прокрутке каталога. Прокручиваются только поля; нижний блок с кнопкой генерации остаётся виден. На мобильном два шага: выбор стиля/тренда → настройки, с закреплёнными снизу кнопками «Далее» и «Начать генерацию». Возврат сохраняет фото, текст и параметры. Над мобильной кнопкой показывается только название выбранного шаблона. Кнопки генерации показывают примерную стоимость с белой фирменной иконкой токена из баланса. `src/generation-cost.js` рассчитывает оценку локально по числу слайдов или качеству видео; списания баланса нет.

Промпты и пути новых ассетов: `docs/carousel-image-prompts.md`, `docs/trends-image-prompts.md`.

Главная содержит общую для всех режимов шторку вдохновения, баннеры и примеры. Текстовые модели имеют собственные карточки запросов. В нижней части сайдбара — меню профиля; вход показывает локальный демо-флоу с кодом `123456`.

Изображения и видео раскрываются эффектом Libraries.dev Image. При генерации край композера подсвечивает Border Beam. Клик по результату открывает viewer, аудио — настоящий плеер с очередью. Ручная прокрутка истории вверх отключает автоматическое следование.

Строки истории показывают использованные типы чата. На десктопе наведение или фокус показывает More; на мобильном кнопка видна постоянно рядом с типами чата. Доступны переименование, перенос в проект и удаление с отменой. Блок профиля закреплён внизу сайдбара и не прокручивается с историей.

Info в списке ролей и плашке активной роли открывает общую модалку витрины сразу на выбранной роли. Просмотр сохраняет чат, проект и черновик; примеры запросов подставляются в текущий композер.

В режимах изображения и видео введите `@`, чтобы выбрать прикреплённое фото, включая начальный/конечный кадр. Поиск идёт по названию; стрелки и Enter выбирают фото без отправки. Токен можно удалить целиком и вернуть через Undo. Он связан с UUID файла и сохраняется в истории. Удаление вложения превращает его токены в обычный текст. Системы AI получают подготовленную структуру `prompt.parts` после будущего подключения API; текущая генерация остаётся демонстрационной.

### Просмотр документов

В истории доступен чат «Демо: просмотр документов» (локально: `/?chat=molecula-document-demo-v1`). PDF, DOCX и Markdown открываются в изменяемой правой панели или мобильной шторке. Скачивание, разворачивание и закрытие находятся в шапке. Проверка браузерных сценариев: `pnpm test:artifacts`. Подробнее — [docs/artifact-panel.md](docs/artifact-panel.md).
