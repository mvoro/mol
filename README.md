# Молекула — новый композер и флоу чата

React-приложение по секции Figma `2335:87500` (UX rework, iteration 09).

## Запуск

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5190
```

- `/` — работающий флоу чата.
- `/components` — каталог компонентов, вариантов и состояний. Также открывается через «Инструменты».
- `npm run build` — production build в `dist/client`.
- `npm test` — проверки сохранения чатов, проектов, настроек и упаковки приложения.

## Реализовано

Авто / текст / картинка / видео / аудио, собственные настройки и модель на каждый режим. Пустой чат и переписка, ввод многострочного сообщения, отправка и остановка потокового демонстрационного ответа, история чатов, поиск, выбор модели, поиск и выбор роли, описание роли, файлы и обязательные референсы для Kling. Быстрые действия открывают отдельные поповеры значений; вложенность есть только в меню «+». На мобильном — нижние листы. Enter отправляет, Shift+Enter переносит строку; Cmd/Ctrl+1…5 переключает режимы, Cmd/Ctrl+K открывает поиск чатов.

Проекты доступны в верхней серой пилюле и сайдбаре. Создание проекта, вложенные чаты, перенос текущей переписки через верхний переключатель и восстановление после перезагрузки работают через localStorage. Раскрытие проектов и сворачивание сайдбара анимированы. На мобильном у композера ровно 16 px по бокам. Шиммер «Молли ждёт ваш запрос…» проходит по буквам раз в 4 секунды.

Общие TextInput/InputShell используются для имени проекта и поиска чатов, моделей и ролей. Фон, обводка, скругление, Manrope и состояния фокуса заданы в одном месте; высота поля — параметр компонента. Кнопки проекта повторно используют общий стиль pill.

50 сочетаний композера: 5 типов × 5 состояний × 2 устройства. Опциональные панели Assistant / Role / Offer, footer, promo, file chips, UploadRefCard. Галерея повторно использует компоненты основного приложения.

Оригинальные иконки и изображения Figma сохранены локально в `public/figma`, `public/assets/models`, `public/assets/composer`. Шрифты Manrope и Geist загружаются локально. Анимации поддерживают reduced motion; действия с клавиатуры выполняются без анимаций.

## Границы прототипа

AI API, авторизация и платежи не подключены. Ответы в чате демонстрационные; изображения — исходные примеры Figma. Видео и аудио не генерируются. Голосовой ввод использует Web Speech API, когда браузер его поддерживает, и сообщает об отсутствии поддержки. История текстов сохраняется только в localStorage этого браузера; бинарные вложения не сохраняются между перезагрузками. Модели и цены — подписи из макетов, не коммерческое предложение.

## Дополнения текущей итерации

Главная содержит общую для всех режимов шторку вдохновения, баннеры и примеры. Текстовые модели имеют собственные карточки запросов. В нижней части сайдбара — меню профиля; вход показывает локальный демо-флоу с кодом `123456`.

Изображения и видео раскрываются эффектом Libraries.dev Image. При генерации край композера подсвечивает Border Beam. Клик по результату открывает viewer, аудио — настоящий плеер с очередью. Ручная прокрутка истории вверх отключает автоматическое следование.

Строки истории показывают использованные типы чата. На десктопе наведение или фокус показывает More; на мобильном кнопка видна постоянно рядом с типами чата. Доступны переименование, перенос в проект и удаление с отменой. Блок профиля закреплён внизу сайдбара и не прокручивается с историей.

Info в списке ролей и плашке активной роли открывает общую модалку витрины сразу на выбранной роли. Просмотр сохраняет чат, проект и черновик; примеры запросов подставляются в текущий композер.

В режимах изображения и видео введите `@`, чтобы выбрать прикреплённое фото, включая начальный/конечный кадр. Поиск идёт по названию; стрелки и Enter выбирают фото без отправки. Токен можно удалить целиком и вернуть через Undo. Он связан с UUID файла и сохраняется в истории. Удаление вложения превращает его токены в обычный текст. Системы AI получают подготовленную структуру `prompt.parts` после будущего подключения API; текущая генерация остаётся демонстрационной.
