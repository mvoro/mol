# Городской сад

Заметки команды о том, как превратить небольшой двор в зелёное место для соседей. Начинаем с участка **60 м²** и двух недель совместной работы.

## Что хотим получить

- Тихое место для отдыха.
- Местные многолетние растения.
- Понятный календарь ухода.

> Хороший сад начинается с заботы о месте и людях, которые будут им пользоваться.

## План работ

| Этап | Срок | Ответственный |
| --- | --- | --- |
| Замеры и эскиз | Понедельник | Анна |
| Подготовка почвы | Суббота | Команда |
| Посадка | Следующая неделя | Соседи |

## Чек-лист встречи

1. Обойти площадку и отметить солнечные участки.
2. Проверить доступ к воде.
3. Согласовать бюджет и список покупок.

## Календарь полива

Пример данных для общего календаря:

```javascript
const garden = {
  area: 60,
  watering: ["понедельник", "четверг"],
  volunteers: 8,
};

function nextTask(day) {
  return garden.watering.includes(day)
    ? "Проверить влажность почвы"
    : "Проверить состояние растений";
}
```
