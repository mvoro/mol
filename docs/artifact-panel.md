# Просмотр документов

В общей истории появился один чат «Демо: просмотр документов». Прямая ссылка в локальном preview: http://127.0.0.1:5190/?chat=molecula-document-demo-v1. Демо добавляется по постоянному ID и не меняет пользовательские чаты. Реальные PDF, DOCX и Markdown находятся в `public/documents/`.

Клик по вложению открывает правую панель; повторный клик по вложению возвращает скрытый файл. Панель сохраняет ширину и позиции просмотра каждого файла в текущем сеансе. Ширина также сохраняется после перезагрузки. Разделитель поддерживает стрелки (10 px), Shift + стрелки (50 px), Home/End. Ширина меняется свободно, без магнитных точек. Минимумы — 360 px для чата и 300 px для панели; при более узкой рабочей области документ занимает её целиком.

На телефоне документ открывается в шторке высотой 68% или 94% экрана. Верхний handle управляет высотой и закрытием; прокрутка содержимого не двигает шторку. Кнопка разворачивания и клавиатурная активация handle переключают высоту. Escape и кнопка закрытия возвращают фокус; фон заблокирован, Tab остаётся в шторке.

PDF.js выводит реальные страницы с текстовым слоем, масштабом 50–250% и счётчиком текущей страницы. DOCX преобразуется Mammoth в семантический HTML и очищается DOMPurify. Markdown использует react-markdown с GFM и отключённым HTML. Исходные вложения доступны для скачивания; ошибки чтения предлагают повтор. Загруженные пользователем документы сохраняются в IndexedDB отдельно от JSON истории.

## Проверка

- `pnpm test` — unit/regression tests, включая расчёт free-width/min-width, seed и сериализацию документов.
- `pnpm test:artifacts` — Playwright Chromium, работающий local preview на 5190. При необходимости сначала `pnpm exec playwright install chromium`.
- `ARTIFACT_BASE_URL=http://127.0.0.1:5191 node qa/artifact-panel.mjs` — те же сценарии интерфейса на production preview.
- Браузерные сценарии проверяют PDF, DOCX, MD, скачивание исходных байтов, resize/free-width, keyboard, fullscreen/restore, hide/reopen, переключение файлов, reload, retry, повреждённые документы, HTML-инъекции, IndexedDB, мобильные touch-жесты, focus trap, Escape и reduced motion.

## Ограничения

- До 25 МБ на вложение, как в существующем composer. Очень большие многостраничные PDF могут потреблять заметный объём памяти.
- DOCX — адаптивный читаемый документ, не точная копия пагинации Word. Макросы, внешние изображения, SVG и встроенные объекты не выполняются и не загружаются. В Markdown внешние изображения заменяются подписью.
- PDF с паролем показывают состояние ошибки; интерактивные формы/аннотации не активируются. Исходный PDF можно скачать.
- Старые вложения, у которых ранее сохранялось только имя, восстановить невозможно: интерфейс предлагает прикрепить исходник снова.
- Хранение локальное для текущего браузера. При отказе IndexedDB документ доступен в текущем сеансе, а пользователь получает уведомление о невозможности сохранения.
